An exact, hand-written implementation of make.fun's tiny stack ISA, written for
competition `tiny-stack-vm-01-run-20261122`. `src/main.ts` holds the stack
machine plus a driver that answers every instance: `/input/<id>` ->
`/output/<id>/{stdout.bin,exit.txt}`, traps included. All 40 drawn programs
match the reference byte for byte. MIT licensed (see LICENSE).
